# 🏭 Factory Distribution Application

A web-based application designed to streamline and manage the distribution of goods from factories to retailers or warehouses. The system supports real-time inventory tracking, order processing, logistics management, and performance analytics.

---

## 🚀 Features

- 📦 Inventory Management
- 🧾 Order Processing and Tracking
- 🚚 Delivery Route Optimization
- 🗃️ Warehouse Assignment
- 📊 Real-Time Reporting & Analytics
- 👥 Role-based Access Control (Warehouse Manager, SalesRep, production Manager)

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Frontend:** Next.js / HTML & CSS
- **Database:** PostgreSQL / Prisma
- **Authentication:** JWT / OAuth2

---

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/your-username/factory-distribution-application.git

# Navigate into the directory
cd factory-distribution-application

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env
# Then edit the .env file with your configuration

# Run the application
npm start

```
